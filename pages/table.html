Table

Do
  • Wrap tables in .table-wrap.
  • Use tabular figures for numbers, right-aligned, with totals in the foot.
  • Pick the style for the job: records for things people open, compact for figures, striped and sticky for long logs.
  • Make the whole record row open the record, and show a chevron.
Don't
  • Use a table for page layout.
  • Hide columns on phones with no way to see them: the row opens the full record.
  • Colour a whole row to show status: use the status pill.
  • Make a row action look like a status chip: use a button.
