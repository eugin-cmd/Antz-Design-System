Next.js dashboard (MUI)

The dashboard already uses MUI, so the system arrives as a theme. Swapping it in gives every themed MUI component the Antz colours, type, radius and motion without touching screens. Breakpoints stay at MUI's defaults. palette.antz adds Antz-only roles: brand, brandText, focus, tertiary, caution and board.

import { createTheme, ThemeProvider } from '@mui/material/styles';
import { antzThemeOptions } from '@/design-system/antz-mui-theme';

const theme = createTheme(antzThemeOptions({ mode: 'light', contrast: 'standard' }));
export default function App({ children }) {
  return <ThemeProvider theme={theme}>{children}</ThemeProvider>;
}
// Contained primary buttons now render #37BD69 with the #00210C label (7.07:1).

Spacing. The theme keeps MUI's 8px unit and exports antzSpacing: the factors that land on an Antz space step. p: 2 is 16px (--space-4), p: 1.5 is 12px (--space-3), gap: 1 is 8px (--space-2), p: 0.25 is 2px (--space-0-5). Use only those factors; the guardrail check flags any other number (for example p: 3.5, 28px) and names the nearest step.

import { antzSpacing } from '@antz/design-system/mui';
// { 0: '--space-0', 0.25: '--space-0-5', 0.5: '--space-1', … 2: '--space-4', 3: '--space-6', … 8: '--space-16' }
<Box sx={{ p: 2, gap: 1.5 }}>…</Box>   // 16px padding, 12px gap: both Antz steps

React Native

Install a pinned release straight from GitHub; the tag is the version. The theme carries every colour in light, dark and both high contrasts, spacing, radii, type, sizes, motion, shadows (iOS shadow and Android elevation), gradients for expo-linear-gradient, and ready-made colour roles for the status pill, priority tag, sex tag and tag chip. It ships as JavaScript with TypeScript types, so an unknown token fails to compile.

npm install github:eugin-cmd/Antz-Design-System#v1.2.0-beta.6
# upgrade: change the tag; roll back: change it back

One hook for the app

// theme.ts: one hook for the whole app
import { useColorScheme, AccessibilityInfo } from 'react-native';
import { antzTheme } from '@antz/design-system/react-native';

export function useAntz(highContrast = false) {
  const dark = useColorScheme() === 'dark';
  const scheme = (dark ? 'dark' : 'light') + (highContrast ? 'HighContrast' : '') as keyof typeof antzTheme.colors;
  return { t: antzTheme, c: antzTheme.colors[scheme], roles: antzTheme.roles[scheme],
           shadow: antzTheme.shadow[dark ? 'dark' : 'light'], gradient: antzTheme.gradient[dark ? 'dark' : 'light'] };
}

React Native draws one shadow per view, so each shadow token keeps its softest, largest layer. Radial and layered gradients have no faithful React Native form; they are listed in antzTheme.gradientWebOnly. Ready-made React Native components are planned for a later release; until then, build them from these recipes and the component pages.

Figma

  1. Install Tokens Studio for Figma and choose the W3C DTCG format.
  2. Load dist/figma/antz.tokens-studio.json. It holds the sets primitive, base, light, dark, high contrast and compact, plus four themes.
  3. Export to Figma variables. Semantic variables alias the primitives, so a token change in Git flows through on the next import.

Writing variables straight into Figma through its API needs a higher Figma plan; check your plan. The Git token source stays the authority either way: changes made in Figma come back as proposals, not edits.
