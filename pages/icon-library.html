ANTZ Rounded icons

The ANTZ Rounded icon set: 207 icons in line and filled, and 30 animated Primary icons for module navigation. Drawn by the ANTZ icon team; all are drafts for now.

Line icons

No icon matches.

Primary icons

Animated tile badges for module navigation: one icon per module. The SVG follows the tile colour you pick; the Lottie files (one per colour scheme) are in icons/antz-rounded/primary/lottie/. Animation stops under reduced motion.

Per row

Line (proposal): outline icons in the text colour with one accent detail in a green-to-teal gradient (--scale-primary-600 to --scale-secondary-600, 3:1 or more on light and dark). The outline draws on and the accent settles with the elastic ease, once (2.8s); then the icon rests. Hover, focus or tap an icon to replay it. Original drawings: 118 icons in seven groups: the 30 module icons, animals, animal care, health and lab, facilities and maintenance, data and time, and interface icons with micro-animations. Where elements overlap, the front one cuts a small gap into what is behind it, so it reads as solid on any background.

    Which icons to use DD-004

    UseIconsSize
    Controls, navigation, buttons, inputs, lists, tables, statusComponent icons (#i-name), ANTZ Rounded line; filled for the selected state16 to 24px
    Module navigation, empty states, onboarding, confirmationsAnimated line icons, played once; or the still version48 to 72px
    Module tiles in a product that uses the tile launcherPrimary tile icons (one module-navigation style per product)48px and up
    • Animation plays once (2.8s) and rests on its final frame. Add data-icon-replay to the icon or its control to replay it on hover, focus or tap. No loops (WCAG 2.2.2); reduced motion shows the final frame.
    • One animated icon playing in view at a time, never inside dense controls.
    • Missing an icon? Ask the icon team; don't borrow from another set.

    ANTZ Rounded icons

    Do
    • Use line by default and filled for the selected or active state of the same icon.
    • Colour icons with currentColor, from text or semantic tokens.
    • Use Primary icons only for module navigation tiles, with a tile colour whose ink passes AA.
    • Need an icon that isn't here? Ask the icon team: new icons are drawn in the ANTZ icon builder.
    Don't
    • Treat a Draft icon as final in shipped work without checking with the icon team.
    • Mix line and filled in one group of controls.
    • Redraw, stretch or recolour parts of an icon.
