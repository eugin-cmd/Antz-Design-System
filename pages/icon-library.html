ANTZ Rounded icons

The ANTZ Rounded icon set: 207 icons in line and filled, and 30 animated Primary icons for module navigation. Drawn by the ANTZ icon team; all are drafts for now.

The set

Every icon is drawn from scratch on a 24px grid in two styles: line (2px round strokes) and filled (solid, details cut out at 2px). They follow the Material 3 icon guidance with rounded caps and corners. Each tile shows line, then filled. Select a tile to copy its sprite id. Draft means the icon may still change.

Primary icons

Animated tile badges for module navigation: one animated SVG per module, plus a Lottie file for each colour scheme (light, dark and their contrast variants) in icons/antz-rounded/primary/lottie/. The animation stops under reduced motion. The recipe is in primary/STYLE-PRIMARY.md.

In the components

Where an ANTZ Rounded icon means the same thing, the component icon (#i-name) is drawn with it, so every component and screen uses the new drawing with no markup change. They keep the components' 1.8 stroke.

ANTZ Rounded icons

Do
  • Use line by default and filled for the selected or active state of the same icon.
  • Colour icons with currentColor, from text or semantic tokens.
  • Use Primary icons only for module navigation tiles.
  • Need an icon that isn't here? Ask the icon team: new icons are drawn in the ANTZ icon builder.
Don't
  • Treat a Draft icon as final in shipped work without checking with the icon team.
  • Mix line and filled in one group of controls.
  • Redraw, stretch or recolour parts of an icon.
