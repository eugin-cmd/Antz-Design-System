Colour scales

Ten colour families from the ANTZ Design Library, eleven steps each, base at 500. Tokens for illustration, data and marketing; components keep using semantic tokens.

The ten scales

The colour scales from the ANTZ Design Library in Figma: 10 families, 11 steps from 50 (lightest tint) to 950 (deepest shade), with the original colour kept at 500. Each swatch is a token, --scale-<family>-<step>, in CSS, Figma, MUI (palette.antz.scale) and React Native (antzTheme.scale). Under each hex: the label colour that passes AA on that step, and its ratio.

Primary--scale-primary-50 … 950
Secondary--scale-secondary-50 … 950
Tertiary--scale-tertiary-50 … 950
Error--scale-error-50 … 950
Neutral--scale-neutral-50 … 950
Neutral variant--scale-neutral-variant-50 … 950
Success--scale-success-50 … 950
Warning--scale-warning-50 … 950
Caution--scale-caution-50 … 950
Info--scale-info-50 … 950

Primary 500 is the pinned brand colour #37BD69 (FD-001). The Figma library shows #36BC69 there, a retired value; the Figma variable should be corrected to #37BD69.

Scales and tone ramps

The system already has a tone ramp per hue (--green-0 to --green-100, and so on). The tone ramps drive every semantic token, because each tone sits at a fixed lightness and that is what lets the build guarantee contrast. The scales share the same hues and agree at the base, the lightest tints and the deepest shades; their middle steps are spaced differently, so they don't map one to one.

Colour scales

Do
  • Use scales for illustration, charts, marketing and empty states, where a specific step is needed.
  • Put a label on a step only in the colour shown under its swatch.
  • Keep status families for status: error, warning, caution, success, info.
Don't
  • Use a scale token in a component instead of its semantic token (--color-*): scales don't change with dark or high contrast.
  • Use #36BC69 for the brand: it is retired. Primary 500 is #37BD69.

Colour scales

CSS, MUI and React Native
/* CSS */
.empty-art { background: var(--scale-primary-100); color: var(--scale-primary-800); }

/* MUI */
theme.palette.antz.scale.primary[600]

/* React Native */
antzTheme.scale.info[300]

Scales are primitives: one value in every theme. For anything that must work in dark and high contrast, use the semantic tokens.
