    Use it

    Apply to this site

    Every page, table and sample here switches to the theme, in this browser only. It is listed in the brand menu as “name · this browser”. Importing the same slug again replaces it.

    Save into site files

    Pick the design-system-foundation folder. This writes themes/slug.css, themes/slug.antz-theme.json and themes/index.json, exactly as the Python importer would. Then redeploy to publish.

    This browser can’t write into a folder (that needs Chrome or Edge). Download the files instead, or run the importer.

    After downloading

    1. The surest way: from the design-system-foundation folder, run the importer on the theme file. It reads your folder’s own themes/index.json.
    1. Or put the three downloaded files in design-system-foundation/themes/; index.json replaces the one there. It is this site’s current list plus this theme, so use the command instead if your folder has themes the site doesn’t.
    2. Commit it, then publish a new version with node tools/release.mjs.

    Themes in this browser

    Themes applied here that aren’t part of the site files yet. In this browser a theme here wins over the site’s copy of the same slug.

    How it works

    This page runs the same importer as tools/import_theme.py, ported to JavaScript (assets/theme-import.js), so the preview, the files it saves and the report match the command line byte for byte.

    1. Mapping. The Previewer’s parts (page, cards, text, buttons, dividers and so on) set the matching --color-* tokens. A theme built on a Previewer preset is read from its Material 3 roles.
    2. Working out. Hover, pressed, soft, borders, focus, disabled, shadows and the feature gradients are worked out from those colours, and text is pushed until it reaches AA.
    3. Inheriting. Every other token stays ANTZ. A theme that sets no accent keeps ANTZ’s greens for buttons, links, the header and the hero.

    Where a theme lives

    • This browser: “Apply” stores the generated CSS in localStorage (antz-ds-local-themes). Every page loads it before it draws, and the brand menu marks it “this browser”.
    • The site files: “Save into site files”, the downloaded files or python3 tools/import_theme.py put it in themes/. Redeploy and everyone gets it.
    • When the site starts serving a saved theme, this browser drops its own copy.
    Do
    • Check the contrast chips before saving.
    • Set an accent in the Previewer if the brand has one.
    • Redeploy after saving, then remove the browser copy if it is still listed.
    Don't
    • Edit themes/*.css by hand; import again instead.
    • Expect “Apply” to change the site for anyone else.
