# Animals · recently added: style options from Antz Home style 2

Date: 25 November 2026 · Status: draft for System Owner approval · Decision record to follow: DD-007 (proposed)

## Intent

The System Owner wants every element of the Antz Home style 2 page **Animals · Recently added**
(`https://antz-home-style-2.vercel.app/animals-list?from=style-7#recent`) in the design system:
the full page in the Screens library, and each element as an option on the component or pattern
it belongs to. The aim is to give designers and developers **as many style options as possible**,
all inside the system's rules (AGENTS.md, `governance/rules.json`).

The page already exists in the system as Screens → "Animals · recently added" (DD-006, generated by
`tools/style7.py`, `AN_RECENT`). This work adds what that version lacks, as **options alongside the
current styles**, not replacements.

## Goals

- Every visible difference between the reference and our screen is either available as a named
  option (a modifier class or documented markup) or listed below as excluded, with the reason.
- Each option is shown on its component page next to the existing style, with copyable markup.
- The "Animals · recently added" screen is rebuilt from the generator to use the new options, at all
  four frame sizes.
- DD-007 records the additions (status: proposed) for the System Owner to accept.

## Non-goals

- Replacing current styles. The existing look stays the default; new looks are opt-in modifiers.
- Copying the reference's own defects: its phone layout overflows (508px page on a 390px screen).
- New screens beyond this one.

## Anti-goals (would be a failure even if it looks right)

- A second version of an existing component (second card, second side panel, second sort control).
  Everything here is a modifier or slot on an existing component (ANTZ-CMP-01).
- Any invented token, raw value or off-scale size (ANTZ-TOK-02, COL-01, SPC-01, TYP-01, SHP-01).
- A colour pair that fails WCAG AA in any of the four modes (ANTZ-A11Y-04).
- Icons borrowed from outside ANTZ Rounded (DD-004).

## Excluded by the System Owner

- **Dark-green filled buttons with white labels** (Add animal, current page number). FD-003 keeps
  #37BD69 with a #00210C label.
- **The Vantara client logo** in the top bar. The top bar stays as it is.

## Constraints

- Source of truth: `tools/style7.py` (screen markup) → `node tools/docs.mjs` (pages). Component pages
  that are hand-written get generated sections between markers, as `put_section` already does for the
  Animal card page.
- CSS goes in `components.css`, tokens only. EXC-001 covers legacy literals in that file; new rules
  must not add to it.
- Reference values are off our scales (11.5px text, 14px padding, 22px radius, 10px tag text). Map each
  to the nearest token; never copy the raw value.
- The reference's sex-tag colours fail contrast (white on #FA6140 ≈ 3:1, white on #00C2B0 ≈ 2.3:1).
  Match the *look* (solid, vivid fill) with hue tokens whose pairs pass AA.
- Gates before finishing: `node tools/build.mjs --check && node tools/check.mjs && node tools/test.mjs`;
  `node tools/audit.mjs` before any release.

## Approaches considered

- **A. Extend existing components with options (chosen).** Each difference becomes a modifier on the
  component it belongs to, shown on that component's page; the screen is rebuilt from them. One
  library, no duplicates. Cost: a larger DD-007 review.
- **B. A separate "Style 2" set** of screen and component pages. Faster and easy to compare, but it
  creates second versions of card, side panel and sort control, which AGENTS.md forbids. Rejected.

The System Owner chose A, on condition that it breaks no rule.

## Screen

Rebuild "Animals · recently added" in `tools/style7.py` with the options above: photos, clamped names,
soft overview tile, accent count, unread dot, photo avatar, soft module switcher, sort menu, and the
tablet strip. The current look stays reachable on the component pages; the screen shows the new one.

**Scope (decided): this screen only.** The top bar and side panel looks (#5, #6, #9, #10, #11) are
opt-in through parameters on the shared helpers (`modbar`, `modnav`, `module_page`), defaulting to the
current look. Only Animals · recently added passes them. The other ~15 module screens, including
Animals, are unchanged. The mismatch between the two Animals pages is accepted.

## Records and docs

- `governance/decisions/DD-007-…md`, status **proposed**, in the DD-006 format: context (the
  reference), decision (the inventory), exclusions, accessibility notes, affected classes.
- `CHANGELOG.md` under Unreleased.
- Component pages updated through their sources (`docs-src/` or `tools/style7.py` sections), then
  `node tools/docs.mjs`.

## Left to the builder

- Exact modifier names, following the `.block--variant` convention.
- Which hue-ink tokens give the solid sex tags a passing pair, provided they read as coral, teal and sky.
- Whether #6 is a default change or an option (documented either way).
- Mapping of each off-scale reference value to its nearest token.

## Decisions by the System Owner (25 November 2026)

1. **Sex tag colours:** keep the system's colours everywhere. The reference's colour set is not added.
2. **Scope:** the top bar and side panel options are used on this screen only; other screens are unchanged.
3. **Photos:** free licensed photos of the same species, credited in `assets/img/CREDITS.md`. The
   reference app's own photos are not copied.
4. **Excluded:** dark-green filled buttons with white labels, and the Vantara logo.

## Calls made in writing this up (check these)

- Photos are fetched from Unsplash or Pexels pages, cropped and compressed to WebP, as for the banners.
- The panel-collapse icon is requested from the icon team; the current menu icon stays meanwhile.
- New looks are modifiers that default off; nothing changes for existing markup.
