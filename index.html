Welcome

The Antz Design System is the governed source of every visual decision in Antz products. Designers link a pinned release in their prototypes; developers use the generated MUI and React Native themes; every change passes automatic guardrails before it can be published. It succeeds ANTZ Design System Foundation v0.2 and keeps its class names, so existing prototypes upgrade by changing one link.
