# ANTZ Rounded icons: source

Imported from the ANTZ Icon Library and Builder, https://github.com/roshni-draws/icon-library-ads
(commit `263fcafe08c66db5963c3dedc402772e8af08677`, 23 November 2026), on 24 November 2026.

That repository stays the source of truth for drawing icons: its builder app checks every icon against the
guard rails in `STYLE.md` and `guardrails/m3-icon-spec.md`. This folder holds the published assets only.

| Folder | What |
| --- | --- |
| `line/`, `filled/` | 207 icons each, 24px, `currentColor`. All are **draft** (`index.json`). |
| `primary/` | 30 animated Primary tile icons: `svg/` (filled) and `svg-stroke/` (line), one Lottie file per colour scheme in `lottie/` and `lottie-stroke/`. |
| `sprite.svg` | Generated by `node tools/icons.mjs`: `antz-<name>` (line) and `antz-<name>-filled`. |
| `replacements.json` | Which Antz UI icons (`#i-<name>`) are drawn with which ANTZ Rounded icon. |

Changes made on import: the retired brand value #36BC69 was replaced with the pinned #37BD69 (FD-001) in the
Primary SVGs, the Lottie colour arrays and the style notes. Nothing else was changed.

## Updating
1. Copy `library/line`, `library/filled`, `library/index.json` and `library/primary` (without `review.html`) from
   the source repository over this folder.
2. Replace #36BC69 with #37BD69 again if it reappears (`node tools/check.mjs` flags it).
3. Run `node tools/icons.mjs`, then `node tools/docs.mjs`, and update the commit above.
