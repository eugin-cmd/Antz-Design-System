Gradients

Four soft washes give Antz its signature; module and feature gradients mark identity and big figures. Every gradient is a token.

The four washes

From the four reference gradients (reference/Gradients). Each runs corner to corner, top left to bottom right, between two soft tints. They are low intensity, so normal text sits on them comfortably. In light themes each stop is the reference tint at half strength (blended 50% with white). In dark theme the same tokens switch to deep counterparts automatically.

Stat panels

A boxed row of figures can sit on a wash. Pick the wash by what the figures are about, so the colour carries meaning: the same topic always gets the same wash. Labels switch to the darker secondary text automatically, so they stay readable on every part of the gradient.

Do
  • Give each topic one wash and keep it everywhere it appears.
  • Keep a panel with mortality on Primary or Calm.
  • Show at most two different washes on one screen.
Don't
  • Rotate washes at random for variety.
  • Put deaths, alerts or overdue figures on Celebrate.
  • Colour the figures to match the wash; they stay brand green.

Gradient tiers

Three tiers, each with a purpose. There are no other gradients: the guardrail check rejects any linear-gradient() that is not a token.

Token, not image

Each reference SVG is a two-stop linear gradient on a large canvas. Two colour stops and a direction describe it completely, so it ships as a token, not an image. That way it themes (dark counterparts), versions and lints like every other value. Its six stop colours are primitives (--wash-mint, --wash-rose, --wash-butter, --wash-aqua, --wash-sky, --wash-pink). Keep SVG or bitmap files only for illustrations that contain a gradient.

The PDF versions of the gradients mentioned in the brief were not in the reference folder; only the SVGs were inspected.

Module tone, launch and entity gradients (1.2)

From the Kitchen and Diet web app. Tone gradients follow the current module tone (data-tone): --gradient-tone-panel (navigation drawer), --gradient-tone-tab (active rail tab) and --gradient-tone-band (module band). Launch gradients colour the round module tiles. Petrol is for entity headers, and text-brand for one display headline per screen. See Navigation drawer and Launcher and headers.

Gradients

Do
  • Use one wash per screen, on a large area.
  • Put the primary wash on welcome and hero bands.
  • Keep text on washes in the normal text colours.
  • Use feature gradients only behind large figures.
Don't
  • Put a gradient on buttons, chips or inputs.
  • Use gradients in charts or to show status.
  • Place the rose-ended washes next to error states (rose equals the error container).
  • Write your own linear-gradient().
  • Use module tones or launch gradients to show status.
