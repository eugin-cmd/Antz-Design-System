Light and dark

Dark is designed, not inverted: green-tinted night neutrals, surfaces that get lighter as they rise, softer status fills, and brand text in tone 80. The brand fill stays exactly #37BD69 in both themes, so a main button looks the same everywhere.

High contrast

For bright outdoor and clinical use, and anyone who asks the OS for more contrast. It follows prefers-contrast: more automatically, or forces with data-contrast="high". Secondary text becomes primary text, borders darken, and the brand fill moves to tone 30 with a white label (light) or tone 90 (dark). Every pair is checked in this mode too.

Compact density

For data-dense tables and forms (pharmacy stock, administer medicine). data-density="compact" on any container shrinks control and row heights (34/42/48 to 30/36/40; rows 52 to 40). On touch screens, targets never go below 44px.

Switching and persistence

  • Web: set data-theme, data-contrast, data-density on <html> before first paint. Read the saved choice from storage (or a cookie for server rendering in Next.js) to avoid a flash. Default to the system.
  • MUI: createTheme(antzThemeOptions({ mode: 'dark', contrast: 'high' })).
  • React Native: useColorScheme() for the system mode; store the user's choice; pass antzTheme.colors[scheme] through context.
  • Across devices: save the preference to the user profile once signed in, so it follows the person.

More themes later

A theme is a token set. New themes (an organisation brand, a seasonal campaign) override semantic tokens only, so approved components keep working unchanged. Brand overrides are limited to an approved list. The primary action colour stays #37BD69 unless the System Owner decides otherwise (Foundational change).

Themes

Do
  • Follow the system theme by default.
  • Test every screen in light, dark and high contrast (the theme tester shows all at once).
  • Use compact density only for data-dense work.
Don't
  • Hard-code a colour for one theme.
  • Invert colours to make dark mode.
  • Shrink touch targets below 44px in compact mode.
