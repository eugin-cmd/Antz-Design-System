Module bar and side panel

The module home (modhome) stacks the module bar over the body: the side panel and the main column. The module switcher opens a grid of every module. The breadcrumb shows on desktop. The side panel groups pages under overline headings, shows counts (danger counts in red), opens sub-pages and folds to icons. A section head puts pickers beside a title.

Soft side panel

Add modnav--soft for a quieter panel: the overview tile keeps its tint but drops the outline, and the active page's count turns brand green (--color-accent-text). The default panel stays as it is; use one style per product.

Tinted panel and tablet strip

Two layout options for list pages. modhome--tinted sets the main column on the canvas tint (--color-bg-canvas) so a white list panel stands off it. modhome--strip turns the side panel into rows above the list on tablets (600 to 840px wide): the overview tile first, then the pages with their counts. Phones always show the strip. Resize the frame or open Animals · recently added to see both.
