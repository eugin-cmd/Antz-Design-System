Pin, upgrade, roll back

  1. Pin: link releases/vX.Y.Z/tokens.css and components.css. Never link the repository root.
  2. Upgrade: read the changelog, change the version in the link (or the package version), check the screens in the theme tester, run the guardrail check, ship.
  3. Roll back: put the previous version back in the link. Only that product changes.
  4. Compare: git diff v1.2.0-beta.7 v1.2.0-beta.7 -- tokens/src components.css; each release's CHANGELOG.md lists what changed.

Snapshots and previews of unreleased work

Releases are the frozen versions. Between releases, every deploy is kept as a snapshot, labelled with the commit it came from, at its own permanent address (https://<id>-antz-design-system.eugin-736.workers.dev). Work that isn't released yet can still be opened, shared and compared.

  • Make the current commit live: node tools/deploy.mjs. Only committed work goes up.
  • Preview without going live: node tools/deploy.mjs --preview my-change → https://my-change-antz-design-system.eugin-736.workers.dev (any name you choose).
  • Show any past state: node tools/deploy.mjs --ref v1.2.0-beta.3 --preview beta-3.
  • Unlisted, not private: every deploy adds deploy/robots.txt and the noindex header, then checks they are live, so search engines stay away. Anyone with the link can still open the site.

Why a release can't change

Publishing writes MANIFEST.json with a SHA-256 fingerprint for every file, and records the manifest's own fingerprint in releases/index.json. node tools/release.mjs --verify runs on every commit and fails if any published file was edited, added or deleted. To change something, release a new version.

Deprecation and compatibility

  • A token or component is marked deprecated in a minor release, with its replacement named. The check warns, and a migration note explains the move.
  • It is removed no earlier than the next major and at least six months later.
  • The previous major keeps getting fixes for six months after a new major.
  • Products are never forced to upgrade on release day.
