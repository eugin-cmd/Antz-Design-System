Tag strip

The record hero shows the latest four tags and a +N button that opens the Tags tab. Chips keep their own backgrounds, so they read on any photo. On phones the strip wraps to two lines and still shows four.

Add a tag

One side sheet: search, then pick a tag or create one. A new public tag opens New tag; a new private tag is added straight away with the New tag. Then set the priority (the priority picker), an optional deadline or time period, and, for private tags, whether everyone can see it. Add tag stays off until a tag is chosen.

Tag info

Select a chip to open it. The hero has the tag and a switch between Info and the entities that carry it. Info lists category, deadline, type, who added it and when, where, and the roles told about it, then the description. From a record, the head offers Edit and Remove (from this record); from the hub, Edit and Delete.

New tag, category and filter

Tags

Do
  • Show at most four tags in a hero, then +N.
  • Add and edit tags in the side sheet.
  • Say who added a private tag that is not yours.
  • Hide New tag, Edit and Delete from people without tag permissions.
Don't
  • Show a tag's priority by colour alone.
  • Put the full tag list in the hero.
  • Delete a tag without asking.
  • Open a second sheet on top of a sheet; New tag replaces Add tag.
