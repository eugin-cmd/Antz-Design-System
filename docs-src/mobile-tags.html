My tags hub and tag entities

Search and filter, public or private, where the tag is used, then tags by category. Select a tag to see the animals and places that carry it, or its info.

Public tags and a new tag

Tags by category, and the categories themselves. New tag is a full page on the phone; Used on opens a bottom sheet.

An animal's tags

The hero carries the latest four tags and +N. The Tags tab splits public and private; private shows my tags and tags by others. With none, an empty state says what private tags are.

Add, see, edit and remove

Every step is a bottom sheet on the phone (drawer--bottom). Add a tag: choose or create it, then its priority and, for a private tag, whether everyone sees it, in the same sheet. Without permission to create public tags, a caution note says what to do instead. Removing asks first.

Tag history

Every change to the animal's tags, newest first.

Do

  • Keep one floating add button per screen.
  • Put priority and visibility in the same Add tag sheet.
Don't
  • Tint a sheet header with the priority colour: the chip carries it.
  • Stack a speed dial under the add button.
  • Use white labels on green buttons.
